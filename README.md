Задание из двух этапов. Первый этап в Octave, второй - в Python.

Шаг 1. 

а. Реализовать функцию func1.m, выполняющую обработку трехмерного массива, представляющего собой информацию о цвете точек некоторого изображения в формате RGB uint8 по следующему правилу.
Рассматривать значения интенсивности красного, зеленого и синего цветов точек в последовательных строках изображения как координаты вектора в трехмерном пространстве. 
Для векторов, значения модуля которых отличаются от среднего значения модуля всех векторов более чем на 3 среднеквадратичных отклонения 
заменить цвет соответствующей точки за счет масштабирования рассматриваемого вектора таким образом, чтобы величина модуля данного отличалась от среднего значения на 3 среднеквадратичных отклонения с сохранением знака отклонения 
Координаты точек, чей цвет был модифицирован, необходимо собрать в массив coords, который будет являться первым результатом функции.
Вторым результатом является модифицированный массив - изображение в формате RGB uint8.
б. Реализовать скрипт step1.m, позволяющий загрузить произвольно взятое полноцветное растровое изображение, обработать его с помощью функции func1.m и отобразить модифицированное изображение,
а также сохранить массив coords в текстовый файл.
